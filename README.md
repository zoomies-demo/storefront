# storefront

[![CI has the Zoomies](https://zoomies.sh/badge.svg)](https://zoomies.sh)

A small shopping cart library: items, quantities, a percentage discount and
prices kept in whole pence.

This repository belongs to the public demo of
[Zoomies](https://zoomies.sh), a self-hosted GitHub Actions runner fleet. It
exists to give the demo fleet something to check out and build. The workflows in
`.github/workflows/` run on a schedule on a Zoomies runner, which is the point:
every job you can see in the demo's web UI came from a repository like this one.

```sh
npm test
```

There are no dependencies to install.
